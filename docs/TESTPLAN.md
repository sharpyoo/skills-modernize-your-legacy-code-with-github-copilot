# COBOL Student Account Program Test Plan

This plan describes characterization and business-acceptance tests for the current console application. Unless a case says otherwise, start a fresh application process and enter each menu choice or amount when prompted. Amounts use up to six digits before and two digits after the decimal point; the program displays no currency symbol.

The current implementation does not validate positive amounts or overflow, and it does not persist balances between runs. Cases that need a business decision or have behavior not defined by the source are called out in Comments rather than assuming a desired rule. These cases should be agreed with stakeholders before they become pass/fail requirements for the Node.js version.
